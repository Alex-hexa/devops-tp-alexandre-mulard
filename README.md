# Kanban

Cette application est une application Kanban qui permet de gérer des tâches.

## Stack

- Express
- React
- Docker

## Lancer le projet

### Backend

```bash
cd backend
composer install
symfony serve --no-tls
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
